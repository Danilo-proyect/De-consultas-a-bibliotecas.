00 — CONTEXTO

SELECT hace más que mostrar datos

La sentencia SELECT permite transformar los datos a nivel de visualización mediante columnas calculadas, operadores y funciones de una sola fila. Entre sus herramientas están la conversión de tipos de datos y las expresiones condicionales.

Al relacionar estos conceptos con Steamworks, podemos observar cómo ideas similares sirven para trabajar con fechas, precios, nombres localizados, regiones y otros datos de una plataforma de gran escala.

01 — CONVERSIÓN

Fechas y precios globales

Oracle puede realizar conversiones implícitas o explícitas. La conversión explícita permite definir con mayor claridad el formato esperado y ayuda a que las sentencias sean más fiables.

TO_DATE

Convierte una cadena que representa una fecha en un valor de fecha según el formato especificado. Puede aplicarse a datos como DateLocal o MonthCohort.

Modificador FX

Exige coincidencia exacta entre el texto y el modelo de formato, incluyendo puntuación y espacios.

TO_CHAR

Convierte valores numéricos a caracteres para preparar una representación adecuada en la interfaz.

Formato monetario

Elementos como $ y , permiten presentar símbolos monetarios y separadores de miles.

TO_DATE('06-10-2026', 'DD-MM-YYYY')
TO_CHAR(999999.99, '$999,999.99')
Ejemplo aplicado: el material relaciona estas conversiones con reportes de Wishlists y con la visualización de precios en diferentes monedas.
02 — FUNCIONES GENERALES

Cuando un dato no existe

Las funciones generales permiten trabajar con valores nulos. En el ejemplo de localización de Steam, un nombre localizado puede no existir y entonces se puede recurrir al nombre base.

NVL

Si la primera expresión es nula, devuelve la segunda.

NVL2

Si la primera expresión no es nula devuelve la segunda; si es nula, devuelve la tercera.

NULLIF

Compara dos expresiones. Si son iguales devuelve nulo; si son distintas devuelve la primera.

Fallback

Permite representar la idea de usar un valor base cuando una traducción o valor alternativo no está disponible.

NVL(nombre_localizado, nombre_base)
03 — LÓGICA

CASE y DECODE para tomar decisiones

CASE y DECODE permiten implementar procesamiento condicional semejante a una lógica IF-THEN-ELSE dentro de SQL. El material lo relaciona con ajustes de precios según bloques geográficos.

CASE region
  WHEN 'USD_LATAM' THEN precio_latam
  WHEN 'USD_CIS'   THEN precio_cis
  ELSE precio_base
END

En una expresión CASE simple, el servidor busca el primer WHEN ... THEN que coincida y devuelve su resultado. DECODE ofrece una forma más condensada de comparar una expresión con distintos valores de búsqueda.

04 — CIERRE

Una consulta puede transformar la experiencia

La anidación de funciones de una sola fila permite combinar conversiones, tratamiento de nulos y decisiones condicionales dentro de una misma consulta. Estos conceptos ayudan a comprender cómo los datos pueden prepararse antes de mostrarse al usuario.
